# FC-Mobile-eFootball
Application communautaire dédiée à FC Mobile et eFootball. Ajoutez vos amis avec leur identifiant ou code ami, suivez vos matchs, consultez vos résultats et analysez vos performances. Créez des groupes, discutez publiquement et partagez vos résultats avec d'autres joueurs. Une seule plateforme pour réunir les passionnés des deux jeux !
